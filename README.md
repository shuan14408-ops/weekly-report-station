# 畢業專題週報站

學生每週回報專題進度、遇到的問題、下週計畫與需要的材料；老師看全班總覽、備料清單，並回覆。
班級名單與 12 週目標已內建。週報資料存在開啟這個網頁的那台裝置的瀏覽器裡。

## 部署（GitHub Pages）

1. 把 `index.html` 和這個 README 放進公開的 repo。
2. Settings → Pages → Branch 選 `main`、資料夾 `/ (root)`，按 Save。
3. 一兩分鐘後開啟 Pages 給的網址。

## 使用方式

- 固定用同一台裝置、同一個瀏覽器開，資料才會在。學生輪流在這台裝置填，或由老師代填。
- 每週到「名單與設定」按「匯出備份」，把檔案存到雲端硬碟。換裝置時用「匯入備份」還原。
- 不要用無痕視窗，清除瀏覽器資料會把週報一起清掉。
- 名單請用代稱，不要輸入姓名、電話、住址。
